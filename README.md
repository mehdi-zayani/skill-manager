# Skill Manager

A REST API for managing IT skills, built with Java, Spring Boot, PostgreSQL and Angular.

## Overview

Skill Manager is a full-stack application designed to manage a catalog of IT skills. It provides a REST API and a simple web interface to create, browse, search, update and delete skills.

## Tech Stack

**Backend**
- Java 25
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Flyway

**Frontend**
- Angular
- TypeScript
- SCSS

**Tools**
- Maven
- Docker Compose
- Git

## Features

- Manage IT skills through a REST API.
- Organize skills by category.
- Search and filter skills.
- Validate incoming requests.
- Manage database schema changes with Flyway.
